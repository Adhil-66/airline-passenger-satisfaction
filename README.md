# airline-passenger-satisfaction
Exploratory data analysis of airline passenger satisfaction using Python, Pandas, and Seaborn.
Airline Passenger Satisfaction Analysis

Project Overview

This project explores airline passenger satisfaction using Python and exploratory data analysis (EDA). The objective is to identify patterns in passenger feedback and understand how travel class, customer type, service ratings, and flight delays relate to satisfaction.

Objectives

- Clean and prepare the dataset for analysis.
- Explore passenger demographics and travel characteristics.
- Compare satisfaction across travel classes and travel types.
- Analyse flight delays and service ratings.
- Identify patterns that may help airlines improve the passenger experience.

Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

Project Workflow

1. Data loading and exploration
2. Data quality checks
3. Missing-value handling and data cleaning
4. Statistical and exploratory analysis
5. Data visualisation
6. Insight generation

Key Areas of Analysis

- Passenger satisfaction distribution
- Satisfaction by travel class and travel type
- Passenger demographics and flight distance
- Departure and arrival delays
- Inflight Wi-Fi, seat comfort, and entertainment ratings
- Correlation analysis
- Passenger groups with lower satisfaction rates

Project Files

- "airline.ipynb" — Complete analysis and visualisations.
- "train.csv" — Dataset used in the analysis, if redistribution is permitted.

Key Findings

The analysis explores differences in satisfaction between travel classes, the relationship between departure and arrival delays, and how service ratings relate to passenger satisfaction. See the notebook for the detailed results and supporting visualisations.

How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Ensure the dataset is available at the path used in the notebook.
4. Open "airline.ipynb" in Jupyter Notebook or Google Colab.
5. Run the cells from top to bottom.

Install dependencies:

pip install pandas numpy matplotlib seaborn jupyter

Conclusion

This project demonstrates how exploratory data analysis can turn raw airline passenger data into meaningful insights. It provides a foundation for understanding passenger satisfaction and identifying areas for further investigation.
